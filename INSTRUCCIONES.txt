════════════════════════════════════════════════════
  PASO 1 — Instalar Python (si no lo tienes)
════════════════════════════════════════════════════
  Ve a: https://www.python.org/downloads/



════════════════════════════════════════════════════
  PASO 2 — Instalar las dependencias
════════════════════════════════════════════════════
  Abre una terminal (CMD o PowerShell en Windows,
  Terminal en macOS/Linux) dentro de esta carpeta
  y ejecuta:

    pip install -r requirements.txt


════════════════════════════════════════════════════
  PASO 3 — Ejecutar el bot
════════════════════════════════════════════════════
  En la misma terminal, escribe:

    python main.py

  ¡Y listo! Sigue las instrucciones en pantalla.


════════════════════════════════════════════════════
  RESULTADO
════════════════════════════════════════════════════
  Al terminar la búsqueda, el bot crea un archivo
  .TXT en tu Escritorio con todas las ofertas
  encontradas.
